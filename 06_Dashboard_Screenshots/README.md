# Supply Chain Data Analysis – APL Logistics Project

## Project Overview

This project focuses on analysing customer performance, product profitability, discounts and delivery operations using supply chain data.

The main purpose is to identify business performance gaps, understand profitability and suggest practical improvements using data analysis.

## Project Objectives

- Analyse overall sales and profit performance.
- Understand customer and product profitability.
- Study the relationship between discounts and profit margins.
- Evaluate delivery performance and shipping delays.
- Provide practical business recommendations.

## Tools Used

| Tool | Purpose |
|---|---|
| Microsoft Excel | Initial data understanding and preparation |
| MySQL Workbench | Data analysis using SQL |
| Power BI | Interactive dashboard development |

## Project Methodology

1. Data Understanding – Reviewed the available dataset and its columns.
2. Data Preparation – Used Excel for initial data checks and preparation.
3. SQL Analysis – Used MySQL to analyse sales, profit, customers, products and shipping performance.
4. Dashboard Development – Created four interactive Power BI dashboard pages.
5. Business Recommendations – Converted the findings into practical improvement suggestions.

## Key Findings

- Total sales: approximately 36.78 million.
- Total profit: approximately 3.97 million.
- Overall profit margin: approximately 10.78%.
- Late shipments: approximately 57.28%.
- Average shipping delay: approximately 0.57 days.
- Profitable customers: 16,527.
- Loss-making customers: 4,069.
- No Discount category had a 13.09% profit margin, while the High Discount category had a 9.38% margin.

## Business Recommendations

1. **Improve Delivery Performance:** Monitor late shipments, review carrier performance and improve dispatch planning.
2. **Control Discounts:** Introduce discount approval limits and review profit margins before offering large discounts.
3. **Review Customer Profitability:** Investigate loss-making customers and review pricing, discounts and delivery costs.
4. **Improve Product Profitability:** Review product costs, supplier prices and selling prices for low-profit products.

## Project Limitations

- The primary SQL analysis used 180,516 records.
- The earlier Excel workbook contained 180,519 records. The difference of three records was not reconciled.
- The analysis is based on the available dataset. Its connection to actual APL Logistics operational records has not been independently verified.
- The findings show patterns and associations; they do not establish cause and effect.
- The business recommendations are proposed actions and have not been tested through actual implementation.

## Conclusion

This project demonstrates how Excel, MySQL and Power BI can be used together to analyse supply chain performance.

The analysis identifies areas that may need improvement in delivery operations, customer profitability, product performance and discount management.

The project also demonstrates the use of data analysis to support practical business decisions.
